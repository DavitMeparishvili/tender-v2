# Georgian places catalog

The `GeorgianPlace` reference catalog is derived from the GeoNames Georgia
country extract dated 2026-02-09.

- Source: https://download.geonames.org/export/dump/GE.zip
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
- Attribution: © GeoNames contributors
- Selection: active populated places with a recorded population of at least
  500, plus every first- and second-order administrative seat in the extract
- Stored fields: GeoNames id, English and Georgian display names, feature code,
  catalog kind, coordinates, population, and first-order administrative code

The migration contains 224 records. GeoNames describes its data as provided
without a warranty of accuracy, timeliness, or completeness. A future catalog
refresh should update rows by the stable GeoNames id, retain this attribution,
and be reviewed for renamed, duplicated, or inactive places before deployment.
